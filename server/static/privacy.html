What we collect / Hum kya data lete hain

  • Google login details: jab aap Google se login karte hain, to Google humein aapka naam, email address aur Google user ID deta hai. Aapka password kabhi humare paas nahi aata — wo Google ke paas hi rehta hai.
  • Your scripts and videos: jo script aap likhte hain aur jo video banti hai, wo humare server par save hoti hai taaki aap use baad mein dekh aur download kar sakein. Aapki videos sirf aapko dikhti hain — koi aur user unhe nahi dekh sakta.
  • Login session: login rehne ke liye aapke browser mein ek secure session cookie lagti hai (30 din). Isme sirf aapka user ID aur naam hota hai.

What we do NOT collect / Hum kya nahi lete

  • Aapka password (Google login hai, password Google ke paas hai).
  • Aapke bank/card/UPI details (abhi koi payment nahi liya jata — video banana aur download karna muft hai).
  • Aapki location ya contacts.

  • Pollinations, Pexels, Pixabay, Wikimedia Commons — video ke visuals (images/footage) ke liye. Inhe aapka personal data nahi bheja jata; sirf search keywords jaate hain.
